## 一、总体风格

- 风格定位: 赛博朋克 HUD 仪表盘 (Cyberpunk Head-Up Display)
- 关键词: 科技感、精密、克制、专业
- 禁止项:
  - ❌ 圆角 (RoundedRectangle) — 所有容器、按钮、卡片一律禁止
  - ❌ 外部图片资源 — 所有图形必须纯代码绘制
  - ❌ 过度装饰 — 不堆砌无功能的视觉元素

## 二、边框与容器规范

### 2.1 切角多边形 (Chamfered Polygon)
- 所有面板、卡片、按钮统一使用 45° 切角多边形
- 切角计算方式:
  ```
  pts = [x+c, y+h,  x+w, y+h,  x+w, y+c,  x+w-c, y,  x, y,  x, y+h-c]
  ```
- 切角尺寸:
  - 大面板: cut = dp(10)
  - 小卡片: cut = dp(8)
  - 按钮: cut = dp(10)

### 2.2 边框三层结构
每个容器的边框由外到内:
1. 发光层 (Glow): width=dp(4), alpha=0.20
2. 主边框 (Border): width=dp(1.2), alpha=容器指定值
3. 角标记 (Corner Ticks): 四角 L 型标记, length=dp(7), width=dp(1.1)

### 2.3 顶部强调条 (Top Accent Band)
- 位置: 容器顶边内侧
- 尺寸: 宽度=容器宽度, 高度=dp(2)
- 颜色: 跟随容器主色, alpha=容器border_alpha × 0.8

### 2.4 扫描线纹理 (Scanlines)
- 间距: dp(4)
- 颜色: 白色, alpha=0.010
- 范围: 距容器边缘 dp(4) 内缩
- 适用: 面积 > dp(20) 的容器

- 阳爻永远用 GOLD
- 阴爻永远用 CYAN
- 每个容器有且只有一个主色
- 正文统一用 WHITE 或 SOFT
- 背景只用 BG 和 CARD，不自创中间色

## 六、首页布局

### 6.1 核心设计理念
- 六爻用 **0 和 1** 表示，不用传统阴阳爻线符号
- 0 = 阴爻, 1 = 阳爻
- 数字化表达更符合赛博朋克风格
- 每次按住按钮生成一个 0 或 1，共操作 6 次完成一卦
- 按住 = 持续许愿的过程，不是点击

### 6.2 布局结构

```
┌─────────────────────────────┐
│  终端状态行 (时间戳/协议)     │  Caption, CYAN
├─────────────────────────────┤
│  天机                        │  H1标题
│  TIANJI DIVINATION           │  Caption副标题
├─────────────────────────────┤
│                              │
│    ┌─────────────────┐       │
│    │                 │       │
│    │   0 或 1 或 ?   │       │  中央主体: 当前爻的结果
│    │   (大号数字)     │       │  idle时显示"?"并带跳动动效
│    │                 │       │
│    └─────────────────┘       │
│                              │
│    □ □ □ □ □ □               │  六爻进度指示器
│    (已生成的爻用0/1填充)      │
│                              │
├─────────────────────────────┤
│  系统日志式状态文字            │  Caption, DIM
├─────────────────────────────┤
│  [ 按住 · 感应天机 ]         │  HoldButton, 高dp(72)
│  [ 重置 ]                    │  TapButton, 高dp(42)
└─────────────────────────────┘
```

### 6.3 中央主体区行为
- **idle (未开始)**: 显示 "?" 大号字符, 带持续跳动动效(上下浮动+发光呼吸), 吸引用户按住按钮
- **pending (按住中)**: "?" 加速闪烁/旋转, 暗示正在感应
- **reveal (揭示)**: 显示 0 或 1, 伴随粒子爆发, 数字短暂放大后回归
- **complete (6爻完成)**: 显示完整 6 位序列, 如 "1 0 1 1 0 1"

### 6.4 六爻进度指示器
- 6 个等宽方块, 横向排列
- 未生成: 空心方块, DIM色边框
- 已生成阳爻(1): 实心方块, GOLD色
- 已生成阴爻(0): 实心方块, CYAN色
- 当前正在感应的位置: 呼吸闪烁

### 6.5 跳动动效 (idle 状态)
- 中央 "?" 字符持续做以下动画:
  - 上下浮动: 幅度 dp(6), 周期 1.2s
  - 发光呼吸: alpha 在 0.5~1.0 之间循环
  - 目的: 吸引用户注意, 暗示"按住我"
- 参考来源: 墨刀感应页的跳动圆环

## 八、交互规范

### 8.1 起卦流程 (共6次按住)
每次按住生成 1 个爻, 用户需按住 6 次完成一卦:

| 步骤 | 操作 | 结果 |
|------|------|------|
| 按住按钮 | 1.5秒充能, 进度条从左到右 | 生成当前爻 (0或1) |
| 揭示 | 中央大字显示 0 或 1 | 粒子爆发, 进度指示器更新 |
| 等待 | 按钮重置为可按状态 | "?" 恢复跳动, 等待下一次按住 |
| 重复 | 再按住, 再揭示... | 直到6爻全部生成 |
| 完成 | 第6爻揭示后 0.5s | 自动跳转结果页 |

### 8.2 按住 = 持续许愿
- 按住不是简单的"确认"操作
- 它模拟的是"持续注入意念"的过程
- 1.5秒的时长让用户感到"我在参与"

### 8.3 idle 跳动动效
- 未按住时, 中央 "?" 持续跳动
- 目的: 吸引用户操作, 暗示"这里需要你"
- 参考: 墨刀感应页的跳动圆环

### 8.4 粒子效果
- 阳爻(1) = 金色粒子, 每次16个
- 阴爻(0) = 青色粒子, 每次16个

### 8.5 重置
- 重新起卦: 右滑返回首页, 所有状态重置
- 首页重置按钮: 清空已生成的爻, 回到初始状态
