# 天机 TIANJI — UI 变更检查清单
# UI Change Checklist
# 适用范围: 天机项目
# 用途: 每次修改界面代码后，逐条校验
# 对应规范: DESIGN_SPEC.md v1.0
# 最后更新: 2026-04-10

---

## 使用方法

1. 每次修改界面相关代码后，必须跑一遍本清单
2. 每一条都要明确通过或不通过
3. 有任何一条不通过，必须修正后再次检查
4. 大版本重写时，每条都要重新验证

---

## A. 容器与边框

- [ ] A1: 代码中是否有 RoundedRectangle？(grep搜索, 期望: 0个用于容器/按钮的结果)
- [ ] A2: 所有容器是否使用 45° 切角多边形？
- [ ] A3: 切角尺寸是否符合规范？(大面板dp(10), 小卡片dp(8), 按钮dp(10))
- [ ] A4: 边框是否包含三层结构？(发光层 + 主边框 + 角标记)
- [ ] A5: 容器面积 > dp(20) 时是否有扫描线纹理？
- [ ] A6: 是否有顶部强调条？

## B. 配色

## 快速 grep 命令参考

```bash
# 检查是否有 RoundedRectangle 用于容器 (A1)
grep -n "RoundedRectangle" main.py

# 检查是否有配色表外的颜色定义 (B4)
grep -n "Color(" main.py

# 检查是否有外部图片资源 (E1)
grep -n "\.png\|\.jpg\|\.jpeg\|source=" main.py

# 检查最小字号 (C1, C2)
grep -n "font_size=sp(" main.py
grep -n "font_size=sp(9)\|font_size=sp(10)\|font_size=sp(11)\|font_size=sp(12)" main.py
```
